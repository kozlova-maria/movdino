# Dinosaur Simulator 

Программа-симулятор динозавра на языке C.

## Описание
Динозавр перемещается по полю и выполняет команды: движение, создание объектов, покраска клеток.

## Компиляция
```bash
gcc -o dino main.c
чтобы заработал код, введите в командную строку:
./dino input.txt
